# Burger Singh

> Burger Singh is an Indian quick-service restaurant chain founded in 2014 by Kabir Jeet Singh with co-founders Nitin Rana and Rahul Seth, operated by Tipping Mr Pink Private Limited out of Gurugram, Haryana. It sells Indian-flavoured "craft" burgers built on Indian spices and chutneys, alongside fries and sides, desserts and beverages, through a hybrid estate of company-owned and franchised outlets spanning high-street, food-court, express and dine-in formats.

Note: burgersinghonline.com does NOT publish an /llms.txt (verified HTTP 404 on 2026-08-08). This
file was generated by API Evangelist from the company's public site and its live API surface.
Burger Singh is a restaurant operator, not a software vendor: it has no developer program, no API
documentation, no SDKs, no CLI, no MCP server and no agent card. Its only machine-readable
interface is the WordPress REST content API behind its corporate site, which is publicly readable
and documented below.

Careful with the domain. `burgersingh.com` is NOT the company site — it is a domain-parking lander
that answers HTTP 200 for every path, including paths that do not exist, and serves a parking
provider's robots.txt and llms.txt. The live corporate site is `burgersinghonline.com`.

## APIs

The surface below is the WordPress REST API on burgersinghonline.com. It requires no credential —
every operation listed was verified to return HTTP 200 to an anonymous request on 2026-08-08. It is
an incidental CMS surface, not a product: Burger Singh publishes no versioning policy, deprecation
policy, SLA, status page, changelog or developer support channel for it.

- [REST root index](https://www.burgersinghonline.com/wp-json/): Self-describing route table — 12 namespaces, 200 routes, with per-route methods and argument schemas.
- [Site pages](https://www.burgersinghonline.com/wp-json/wp/v2/pages): The 20 published pages — menu family, franchise family, store locator, feedback/complaint, legal.
- [Media library](https://www.burgersinghonline.com/wp-json/wp/v2/media): 576 attachments — menu boards, food photography, outlet imagery, franchise collateral — with size variants and direct source URLs.
- [Categories](https://www.burgersinghonline.com/wp-json/wp/v2/categories): 13 terms. Not editorial — they encode the franchise offer: investment brackets (Less than 26 Lacs, 26 to 60 Lacs, 60 Lacs to 1 Crore) and store formats (Dine-in Only, Dine-in + Take Away, Express Model, Food Court, High Street), plus Hot Deal / Regular Deal / Latest news.
- [Tags](https://www.burgersinghonline.com/wp-json/wp/v2/tags): Registered but empty.
- [Site search](https://www.burgersinghonline.com/wp-json/wp/v2/search): Cross-content search returning id / title / url / subtype.
- [Content types](https://www.burgersinghonline.com/wp-json/wp/v2/types): Registered post types.
- [Taxonomies](https://www.burgersinghonline.com/wp-json/wp/v2/taxonomies): Registered taxonomies and the types they apply to.
- [Statuses](https://www.burgersinghonline.com/wp-json/wp/v2/statuses): publish, acf-disabled.
- [Authors](https://www.burgersinghonline.com/wp-json/wp/v2/users): One public author record.
- [SEO head metadata](https://www.burgersinghonline.com/wp-json/yoast/v1/get_head?url=https://www.burgersinghonline.com/menu/): Rendered SEO head plus the schema.org JSON-LD graph for any site URL.

## Conventions

- Base URL `https://www.burgersinghonline.com/wp-json`. No credential; no key; no signup.
- Pagination is page-number: `page` + `per_page` (1–100; outside that range returns HTTP 400 `rest_invalid_param`). Totals come back in `X-WP-Total` / `X-WP-TotalPages`, and RFC 8288 `Link` carries next/prev.
- `_fields` gives sparse fieldsets; `_embed` inlines linked resources; `context=view|embed` selects the projection.
- Errors are `application/json` with the WordPress `{code, message, data:{status}}` envelope — **not** RFC 9457 problem+json.
- No rate-limit headers, no request-id header, no caching headers are emitted. Content is low-churn; poll infrequently.

## Not available

- No ordering, menu-item, pricing, inventory, loyalty or store-locator API. Online ordering runs on a third-party platform, not on a Burger Singh API.
- The four business-meaningful custom post types on this site — `store_locator` (the outlet estate), `inthenews` (press), `hotdeals` (promotions) and `medialist` — are **not** REST-exposed. `GET /wp/v2/store_locator` returns 404 `rest_no_route`. They have public sitemaps but no API.
- No `/wp/v2/posts` content: the collection exists but returns `X-WP-Total: 0`. The RSS feed at `/feed/` is valid but empty.
- The WordPress Abilities API (`/wp-abilities/v1/abilities`) — the agent-facing capability registry — is registered on this host but returns 401 anonymously. No ability names or schemas are readable.
- `/wp/v2/settings`, `/themes`, `/plugins`, `/menus`, `/block-types`, `/templates` and revisions are all 401.
- No GraphQL endpoint, no MCP server, no A2A agent card, no webhooks or events, no AsyncAPI, no Postman collection, no SDK or package on any public registry.
- No `/.well-known/` documents of any kind, including no `security.txt`. Verified against a control path — the 404s are real, not a soft-404 catch-all.
- No status page, no changelog, no roadmap, no trust center and no published compliance certifications.
